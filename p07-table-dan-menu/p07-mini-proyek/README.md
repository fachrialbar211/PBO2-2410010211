## Deklarasi Penggunaan AI

Dalam pengerjaan praktikum dan mini proyek ini, saya menggunakan
**ChatGPT** sebagai alat bantu untuk:

1.  Memahami materi dan ketentuan pada Modul Praktikum PBO 2 Pertemuan
    7.
2.  Mendapatkan penjelasan serta arahan dalam penyusunan struktur
    program Java Swing.
3.  Membantu mengidentifikasi dan memperbaiki kesalahan kode selama
    proses pengembangan.
4.  Membantu menyusun dokumentasi dan jawaban eksperimen praktikum dalam
    file README.

Penggunaan AI hanya sebagai alat bantu. Penyesuaian kode, pengembangan
aplikasi, serta pemeriksaan hasil akhir dilakukan dalam proses
pengerjaan proyek.

## Informasi Proyek

**Nama aplikasi:** Katalog Buku Perpustakaan\
**Teknologi:** Java, Java Swing, Apache NetBeans GUI Builder, Maven, dan
FlatLaf.

Aplikasi ini dibuat sebagai mini proyek individual untuk menerapkan
penggunaan `JTable`, `AbstractTableModel`, `JMenuBar`, `JDialog`, event
handling, validasi input, pencarian, pengurutan data, serta pengelolaan
data buku.
